# Отчёт: паритет TG-бота с VK (🔔 вместо /list, календарь религий, удаления)

Цель: устранить расхождения TG-бота (`tgcloud/`) с VK-ботом (`lunarreturns.js`),
выявленные при сравнении: кнопка 🔔 вместо команды /list, календарь религии на
год, подтверждение удаления со списком, мгновенное удаление одного события.

## Изменения

### `tgcloud/lib/bot.js`

- **HELP** — убрана строка `/list`; кнопки под ответом: «👎 удалить, 👀 подробно».
- **`relMarkup`** — раскладка как в VK `relKeyboard`: `[🗑, 🔔, ☦️, ☪️]` /
  `[☸️, ✝️, ✡️, ❌]` (добавлена кнопка 🔔).
- **`ownerMarkup`** (новая) — `[🗑, 🔔, ❌]`, админ группы (как `ownerKeyboard` VK).
- **`bellMarkup`** (новая) — `[🔔, ❌]`, участник группы (как `bellKeyboard` VK).
- **`startMarkup`** — личка → `relMarkup`, админ → `ownerMarkup`, участник →
  `bellMarkup`.
- **`eventMarkup`** — кнопка удаления одного события — 👎 (`del1:`), детально —
  👀 (`det:`) (как реакции VK).
- **`upcomingText(chatId, byFullDate = false)`** — новый параметр: `true` —
  сортировка по полной дате ГГГГ-ММ-ДД (подтверждение удаления), `false` —
  по ММ-ДД (список 🔔, как раньше).

### `tgcloud/handlers/message.js`

- Команда `/list` удалена (остался `/today`); неиспользуемый импорт
  `upcomingText` убран.
- Восстановлена настоящая проверка админа:
  `const admin = await chatAdmin(message.chat, message.from?.id)` (тестовый
  `admin = true` убран — роли теперь проверяются моком через `--private/--admin`).

### `tgcloud/handlers/callback_query.js`

- **`rel:`** — первый тап: календарь религии на год (`religiousYear`); второй тап
  (заголовок сообщения совпадает с «☦️ Православные дни») — toggle 🔔/🔕.
  Определение «уже показан» — по `cq.message.text` (как VK по `cmidText`).
- **`bell`** (новый) — список записей (`upcomingText`) в этом же сообщении,
  клавиатура сохраняется (`cq.message.reply_markup`); длинный список разбивается
  (`splitList`).
- **`del`** — подтверждение с показом списка событий, сортировка по полной дате
  (`upcomingText(chatId, true)`).
- **`del:yes`** — текст «🗑 Удалено событий: N» (`db.$count`).
- **`del:no`** — клавиатура восстанавливается по чату/роли
  (`startMarkup` + `chatAdmin`): религии — только в личке.
- **`del1:`** — мгновенное удаление одного события (как реакция 👎 VK), без
  подтверждения; `del1s:` оставлен как fallback для старых клавиатур.

## Проверка

1. Синтаксис модулей (`import()` — парсинг без ошибок).
2. `dev/repl.mjs` (мок SDK): сценарии личка/админ/участник, 🔔, del, del:no,
   rel: (два тапа — календарь → toggle).
3. `node lunarreturns.js test "Костя 1963-09-27"` — VK-бот не затронут, логика
   расчётов в двух копиях синхронна.

## Вне объёма

- Ежедневная рассылка 09:00 МСК (нет планировщика на платформе) — по-прежнему
  только `/today` по запросу.
- Проверка админа в обработчиках кнопок (del/del1) — как в VK, не добавлялась.
