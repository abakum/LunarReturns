# Правка Пётр I.ged

## План

Файл не годился для импорта ботом и содержал родословную ошибку.

Диагноз (parse.js берёт только полные даты `DD MMM YYYY`):

- из 43 персон импортировались 2 — у остальных год рождения без дня/месяца
  («1624», «1648», …) → `gdateToISO` → null → персона пропускается;
- Пётр I числился сыном Марии Милославской (CHIL @I16@ в F1 + FAMC @F1@),
  его мать Наталья Кирилловна Нарышкина в файле отсутствовала;
- в семьях не было MARR — свадьбы не импортировались (0);
- `1 DATE` висел прямо под HEAD (не по GEDCOM 5.5.1).

## Отчёт (2026-10-19)

Исправлено в `Пётр I.ged`:

- всем персонам проставлены полные юлианские даты рождения/смерти по
  историческим данным; где известен только год — `1 JAN` с `3 NOTE Известен
  только год` (Милославская 1624, Салтыкова 1664, Мария Ивановна 1689,
  Феодосия Ивановна 1690, Павел Петрович 1693/1717); даты смерти с известным
  только годом оставлены как есть (для импорта не требуются);

  WIFE в F2; из F1 убран CHIL @I16@, у I16 убран FAMC @F1@;
- во все 9 семей добавлены MARR (DATE+PLAC): 16 JAN 1648 Москва; 22 JAN 1671
  Москва; 09 JAN 1684 Москва; 06 FEB 1689 Преображенское; 19 FEB 1712

## Дополнение: парсер не ломает импорт при «только годах» (2026-10-19)

Правка логики в обеих копиях (`lunarreturns.js`, `tgcloud/lib/parse.js`) —
`gdateToISO`:

- «1624» → `1624-01-01`; «MAR 1662» → `1662-03-01` (неполная дата — первым
  числом известного месяца/года);
- квалификаторы ABT/EST/CAL/BEF/AFT срезаются («ABT 1624» → год);
- полные даты и прежнее поведение («не-дата» → null) не изменились.

`dev/sync-check.mjs`: в гедком-фикстуру добавлены I4 (год рождения и год
смерти) и I5 (ABT MAR) + прямые проверки `1624-01-01` / `1669-01-01` /
`1662-03-01`; тест проходит.

`Пётр I.ged` после этого упрощён: шитые «1 JAN … + NOTE» у персон с
неизвестным днём (Милославская 1624, Евдокия-младенец 1669, Павел 1693/1717,
Салтыкова 1664, Мария 1689, Феодосия 1690) заменены на чистые года; NOTE
о конвенции переписан. Статистика импорта прежняя: {persons:44, links:68,
weddings:9}; repl-импорт успешен, Милославская = «1624-01-01».

`node --check` обеих копий — OK; `dev/sync-check.mjs` — синхронны;
`lunarreturns.js test` — OK. Пуш ТГ: `npx tgcloud push` (миграция не нужна).
