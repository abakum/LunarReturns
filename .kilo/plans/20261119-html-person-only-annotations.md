fix(tree): limit HTML annotations to the selected person

## Решение

- В HTML-аннотации показывать только выбранную персону: имя, её даты, время, места и личные примечания, включая структурированные события.
- Не выводить родителей, супругов, детей, семейные строки брака/развода и семейные примечания: связи уже представлены диаграммой.
- Изменение аннотаций относится к HTML обоих ботов; PDF сохраняет радиус аннотаций 1. TXT и навигация диаграммы не меняются.
- Исправить `tg-Husband-5: GED Next` в обоих ботах: экспорт по радиусу не должен заново добавлять датированных супругов, исключённых при отборе. HTML наследует исправленный состав вложенного GEDCOM.

## Реализация

1. В `tgcloud/lib/flat.cjs:createFlatAnnotationText()` добавить необязательный параметр радиуса с текущим значением по умолчанию `1`. Для `0` выбирать только запись `row.xref` и передавать в `flatTreeText()` пустой список семей. Простая замена радиуса в `focusListKeys()` недостаточна: нынешняя фильтрация семей по касанию персоны может сохранить семейные события или именные заглушки супругов. Остальную ветку оставить прежней.
2. В `tgcloud/lib/viewer.cjs:viewerAnnotations()` передавать радиус `0`. Сохранить заголовок, преобразование `^` в переносы, сокращение мест и фильтрацию по экспортированным INDI. Не менять исходные записи и встроенный GEDCOM. Пустой результат для неизвестного xref сохранить.
3. Расширить `dev/viewer-check.mjs`: связанная персона с родителями, супругом и ребёнком; семейные даты и заметки с уникальными маркерами. Проверить сохранение личных данных и отсутствие всех чужих и семейных маркеров. Включить персону без даты рождения, несколько семей и личное структурированное событие. Проверить, что аннотации остальных персон по-прежнему доступны отдельно.
4. Добавить регрессионные проверки общего генератора: радиус `0` выдаёт только выбранную персону, вызов без параметра сохраняет прежний результат радиуса `1`. Проверить отсутствие мутаций снимка и неизменность GEDCOM внутри HTML. В браузерном тесте подтвердить персональный текст всплывающей аннотации и сохранение родственников на диаграмме.
5. В TG и VK оставить в `FAM` только выбранных датированных супругов и убрать их повторное включение в `INDI`. Сохранить оставшуюся половину семьи, её события, бездатные заглушки и исходные роли. Дополнить интеграционный тест проверкой ссылочной целостности.
