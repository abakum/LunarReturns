# 🗑 в фокус-контексте: удаление родни в радиусе + каскад связей

## План

Запрос: если 🗑 (удаление списком) нажимается на фокус-сообщении, список
удаления должен быть тем же, что у 🔔 в этом фокусе (по радиусу родственности);
при удалении персон удалять и их связи.

Подход:

1. VK: кнопка 🗑 в `focusKeyboard` несёт payload `{c:"del", k, r}`; подтверждение
   и `del:yes` тоже. Ветв `del` строит список через `focusListText` (дословно
   как тело 🔔: `focusWithSpouses(focusKeys(...))` + ярлыки родства), ветв
   `del:yes` удаляет жертв по одному `deleteEventCascade` (связи, свадьбы,
   семьи, висячие кандидаты — каскад как при одиночном удалении).
2. ТГ: ключ/радиус не влезают в callback_data (64 байта) — фокус-контекст
   определяется по таблице `focusView` по `message_id` (тот же приём, что у
   `foc*`-кнопок). После удаления — чистка устаревших `focusView`-строк
   удалённых персон; клавиатура снимается явно (повторный тап по висячей
   кнопке не должен уйти в глобальное удаление).
3. Глобальный 🗑 (справка/«/»-сообщение) — без изменений.
4. Проверки: `node --check`, `dev/sync-check.mjs`, repl-сценарии (фокус r1,
   фокус r2 с дедом, регрессия глобального), `lunarreturns.js test`.

## Отчёт (2026-10-19)

Изменения:

- `lunarreturns.js`:
  - `focusKeyboard`: 🗑 → `{c:"del", k:key, r:radius}`;
  - `handleEvent`: извлечение `fd` (k/r) из payload del/del:yes;
  - ветв `del`: фокус-режим — заголовок `focusHead` + «Удалить родню в
    радиусе?» + список `focusListText` (радиус зажимается по `focusDepth`);
    кнопка Yes несёт k/r;
  - ветв `del:yes`: фокус-режим — жертвы = множеству фокуса (персоны + свадьбы
    «Имя+Имя» по `focusHasPair`), удаляются каскадом `deleteEventCascade`
    (связи/семьи/свадьбы чистятся), итог «Удалено событий: N» + справка.
- `tgcloud/handlers/callback_query.js`:
  - `del`/`del:yes`: фокус-контекст по `focusView` (message_id); список и
    удаление — как в VK (радиус зажимается по `focusDepth`);
  - кнопка подтверждения в фокусе — «🗑 удалить родню» (глобально — «🗑
    удалить всё» как раньше);
  - после фокус-удаления: `editText(..., {inline_keyboard: []})` + чистка
    `focusView`-строк удалённых персон.

Проверено (repl, `--admin`):

- Фокус r1 на ребёнке (Отец+Мать→Ребёнок, семья, +Посторонний): 🗑 → тост
  «Удалить родню в радиусе?», сообщение `1⃣ Ребёнок … / Удалить родню в
  радиусе? / Отец … родитель / Мать … родитель / Ребёнок …`, кнопки «🗑
  удалить родню»/«❌ отмена»; подтверждение → «Удалено событий: 3», в базе
  остался только Посторонний, links/fams пусты.
- Фокус r2 (добавлен Дед→Отец): после «2⃣» (тост «от дедов») список
  подтверждения включает «Дед … прародитель», Постороннего нет.
- Регрессия глобального 🗑 со справки: «Удалить все события чата?» →
  «🗑 удалить всё» → «Удалено событий: 2», база пуста.
- `node --check` обеих копий, `dev/sync-check.mjs` — синхронны,
  `lunarreturns.js test` — OK.
