feat(viewer): add searchable person navigation and history

## План

- Заменить список персон комбобоксом с алфавитной сортировкой и фильтрацией.
- Хранить выбранную персону во фрагменте URL, восстанавливать выбор при открытии ссылки и навигации назад/вперёд.
- Различать курсоры карточки и имени, показать закрываемую подсказку на тач-экранах.
- Пересобрать просмотрщик и проверить локальный файл в Chromium, экспорт TG/VK и синхронность.

## Отчёт

- Комбобокс сортирует отображаемые имена по русскому алфавиту и фильтрует их по нескольким словам, включая фамилию, год и ID; поддерживает клавиатуру и тач.
- Фрагмент `#person=…` восстанавливает персону при открытии файла и при переходах назад/вперёд без перезагрузки. Повторный выбор не дублирует запись истории, а ссылка на имени открывает только роспись.
- Карточка использует курсор `pointer`, имя — `help`. Подсказка для тач-экрана скрывается по кнопке или после выбора карточки; при доступном sessionStorage выбор запоминается на сессию.
- `npm run build:viewer`, `npm run test:viewer`, `node dev/sync-check.mjs` и `git diff --check` прошли. Деплой не выполнялся.
