## Отчёт

Реализовано:

- parseTree/parseTreeLine отделяют note у бездатной маркированной персоны
  и именного супруга; следующие ^ остаются переносами NOTE.
- Inline # обрезается до разбора полей/notes. noGraft определяется по
  исходной первой непустой строке, включая BOM, до обрезки комментариев.
- flatTreeText выводит note у nameOnly; существующие applyTree/flatRows
  сохраняют notes семей с marr=null. Повторная именная ссылка на супруга
  без note больше не стирает ранее сохранённое примечание.
- GED-экспорт обоих адаптеров теперь передаёт NOTE/CONT бездатных супругов
  и детей. Отсутствующие даты не добавляются.
- Канон gedText в parse.cjs заменяет # на № в импортируемых NAME,
  NOTE/TITL/CONC/CONT и PLAC рождения/смерти/похорон/свадьбы/развода.
  Структура, исходные xref и ссылки не меняются. При превращении xref
  в текстовый служебный суффикс имени тоже применяется gedText.
- Добавлена hash-text-xrefs-dateless-notes.ged с xref I#1/F#1,
  бездатной парой и семейными notes; обновлены существующие dev checks
  и устаревшие ограничения -+=.md. README дополнительно не изменялся.
