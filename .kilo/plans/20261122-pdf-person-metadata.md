feat(pdf): add person title and parent authors to document metadata

Добавить в PDF стандартный словарь `/Info` с UTF-16BE. Для фокусного PDF: `/Title` = `Имя\nДР`, `/Author` = имена известных родителей через `; `, `/Subject` = описание радиуса как в EPUB. Для полного дерева записать только `/Title`. Использовать полный снимок семей для родителей, не менять диаграмму, аннотации и имена файлов. По уточнению пользователя тот же перенос записать в `dc:title` EPUB, не меняя авторов и содержимое книги. Проверить кириллицу, буквальный перенос в метаданных и свойства PDF через Poppler в офлайн-экспортах TG/VK.

## Отчёт

В PDF добавлены свойства документа, у выбранной персоны заголовок содержит настоящий LF между именем и датой рождения. Тот же LF записан в EPUB без подзаголовка. Метаданные проверены в файлах обоих ботов для полного дерева и радиусов 1 и 2, включая кириллицу, родителей и описание радиуса. Прошли `node dev/viewer-repl-check.mjs --metadata-only`, `node dev/viewer-check.mjs`, `node dev/sync-check.mjs` и `git diff --check`. Деплой не выполнялся.
