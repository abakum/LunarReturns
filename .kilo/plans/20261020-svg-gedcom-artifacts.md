# 2026-10-20 — Гедком-древо файлами: tree.ged + tree.svg

## План

Тап 🧬 («tree»/«foctree» и фокусные), «/gedcom», «/gedcomN» (и reply-фокус) —
одна и та же реакция: вместо текстового гедкома отправляются **файлы**:

- **`tree.ged`** — всегда (содержимое `gedcomText(peerId/chatId, keys)`), при
  любом размере дерева;
- **`tree.svg`** — диаграмма «линии жизни» (bars birth–death, вертикали
  родитель→ребёнок в год рождения ребёнка, точки на строках) — только если
  персон **< 35** (`SVG_MAX`).

Отказ от рассмотренных вариантов: PNG через `@fulgur-rs/chart-node` —
нативный Rust-аддон, в V8-изоляте платформы TG недоступен (нет npm/node API);
печать через PDF — лишний рендерер; ссылка на vega.github.io/editor
(«Open the Chart in the Vega Editor») — не влезает в сообщение (URL длинный).

### Чистая логика (дословные копии)

- 새 `tgcloud/lib/chart.js` ↔ блок в `lunarreturns.js` сразу после
  `gedcomText`: `SVG_MAX/KIND_W/TITLE_H/ROW_H/PLOT_W/PAL/COLOR_OF/FAM_COLORS/
  KIND_WORD`, `kindOf(kin, sex)`, `chartSvg(title, rows, links)`.
  - партнёр `rows`: `{name, birth, death|null, type}` — type из палитры
    (assert «тип вне палитры»);
  - `kindOf`: одиночный ярлык `kinLabel` («отец», «мать», «дедушка», …) →
    категория палитры; составные/супружеские/compound («муж тёти», «жена
    внука») → пол (Мужчина/Женщина) или «Родня», если пол неизвестен;
  - без даты смерти → без тултипа «Жил» (SVG статический — тултипов нет) и
    бар от рождения **до правого края** графика;
  - ключ человека «Имя год»; сортировка строк (год рождения, имя);
  - семья связи «Имя1 и Имя2»/«Имя» — цвет по кругу FAM_COLORS (первое
    появление); легенды: категории (в порядке палитры, только использованные)
    + семьи, перенос строк;
  - assert'ы: персоны пусты, ключ неуникален,death<birth, имя не найдено,
    родителей не 1–2, родитель не старше ребёнка.
- Сборка данных по гедком-семантике (fragment matching gedcomText):
  `chartFor(peerId/chatId, keys, hero, title)` в `lunarreturns.js` и
  `tgcloud/lib/bot.js`: recs (без «Имя+Имя»), parentsOf из fams (усечение до
  фрагмента) + сырые links (дедуп по семьям), kinLabel к герою (фокус).

### Платформенная отправка

- **VK**: `vkUploadDoc(peerId, title, content)` — `docs.getMessagesUploadServer`
  (type doc) → multipart POST (`FormData`/`Blob`, Node 18+) → `docs.save`;
  `messagesSend(+attachment)` — одно сообщение с 1–2 вложениями. Заголовок
  (caption) — head («🧬 Гедком-древо чата» или `focusHead`).
- **TG**: `sendGedSvg(chatId, keys, hero, head)` в `tgcloud/lib/bot.js` —
  `api.sendDocument` сначала tree.ged (caption = head), потом tree.svg
  (`image/svg+xml`, caption «🧬 Диаграмма древа: N персон»).
- Фолбэк: ошибка chartSvg/upload → старый текстовый путь (`splitText`);
  диаграмма не строится при ≥ 35 персон (только tree.ged).
- `editOrigin`/правка сообщения по 🧬 больше не делается: вместо правки
  текста — файлы отдельным сообщением (снекбар остаётся).
