# 🔔 toggle сортировки + даты смерти в списках

## План

1. Повторный клик на 🔔 меняет сортировку: ММ-ДД ↔ ГГГГ-ММ-ДД (и обратно).
2. Дата смерти — в списке 🔔 и в списке подтверждения удаления (в обоих
   вариантах 🔔).

Механизм toggle — как у `rel:`-календаря: по первой строке показанного
сообщения. Спискам добавлены различающие заголовки:
`🔔 до дня рождения` (ММ-ДД, первый показ) и `🔔 по датам рождения`
(ГГГГ-ММ-ДД). Строки списков: «Имя ГГГГ-ММ-ДД[ ГГГГ-ММ-ДД смерти][ ЧЧ:ММ]»
(dd из хвоста смерти/DEAT).

Изменения:

- `lunarreturns.js`: `upcomingEvents(peerId, byFullDate = false)` — параметр
  сортировки + дата смерти (r.dd) в строках; константы BELL_MD_HEAD /
  BELL_FULL_HEAD; ветка 🔔 — toggle по `cmidText` (1-я строка); ветка `del`
  (глобальный вариант) — список на `upcomingEvents(peerId, true)` вместо
  инлайн-сборки (туда же попадают смерти и времена).
- `tgcloud/lib/bot.js`: `upcomingText` — deathDate в строках (обе сортировки:
  обслуживает и 🔔, и удаление).
- `tgcloud/handlers/callback_query.js`: те же константы заголовков; ветка
  `bell` — toggle по `cq.message.text` (1-я строка).

## Дополнение: toggle в фокус-списке 🔔 (2026-10-19)

  дате; покрыт в `dev/sync-check.mjs` (сравнение VK/ТГ byFull + ассерт «старейший
  первым»).
- VK `focusText(peerId, key, radius, bell, dd, byFull = false)` — маркер

## Дополнение 2: состояние на кнопке вместо заголовка (2026-10-19, по предложению пользователя)

Маркерная строка-заголовок убрана. Как у религиозных дней, состояние живёт на
кнопке: payload кодирует целевой режим клика.

- 🔕 («bellfull» / «foc:bellfull») → показать список по ГГГГММДД, кнопка
  становится 🔔; 🔔 («bell» / «foc:bell») → по ММДД, кнопка снова 🔕.
  Свежая клавиатура всегда 🔕 → первый клик всегда даёт ГГГГММДД.
- Клавиатурные строители получили параметр bellMode ("full"/"md", по умолчанию
  "full"): VK relKeyboard/ownerKeyboard/bellKeyboard/peerKeyboard/focusKeyboard;
  ТГ relMarkup/ownerMarkup/bellMarkup/startMarkup/focusMarkup.
- Состояние per-message (в payload), не в settings: сортировка — разовый
  просмотр; на старых сообщениях подпись может отставать, но клик всегда
  делает нарисованное.
- Убраны BELL_MD_HEAD/BELL_FULL_HEAD и парсинг текста сообщения.

Критика (принято с оговорками): 🔕 в боте уже значит «выключено» (религии) —
здесь оно значит «полные даты», значение надо выучить; эмодзи-кнопка не может
объяснить режим словами (заголовок был самодокументируемым). Взамен: список
без служебной строки и надёжный toggle, не зависящий от текста сообщения.

Проверено (repl): справка — 🔕 → полный порядок (Анна 1985 → Борис 1990 →
Вера 1992, без заголовка) и кнопка 🔔 → ММ-ДД порядок и снова 🔕 → …;
фокус — 🔕 → Отец(1950) → Мать(1955) и кнопка 🔔 → ММ-ДД и снова 🔕; даты
смерти на месте, 🗑 в фокусе сохранён. `node --check` ×3, `dev/sync-check.mjs`
— OK. Пуш ТГ: `npx tgcloud push`.

## Дополнение 3 (итоговое): колокольчик = подписка, как религиозные дни (2026-10-19)

Финальная семантика по уточнению пользователя — колокольчик переключает
**подписку**, сортировка следует за подпиской:

- первый клик показывает список, НЕ меняя подписку (как первый клик на религию
  показывает календарь); сортировка по текущей подписке: 🔔 вкл — ММ-ДД,
  🔕 выкл — ГГГГ-ММ-ДД;
- клик по уже показанному списку переключает подписку (settings), переворачивает
  кнопку и пересортировывает;
- состояние в settings чата (персист между сообщениями и сессиями), подпись
  кнопки = состояние подписки (как `icon + (🔔/🔕)` у религий), payload один
  («bell» / «foc:bell»);
- «уже показан» — текст сообщения является префиксом рендера списка И длиннее
  заголовка фокуса (заголовок `1⃣ Имя дата` сам по себе префикс — иначе первый
  клик ложно считался бы повторным).

Изменения: `tgcloud/schema.js` — колонка `settings.bell` (boolean, default
true) → **нужен `npx tgcloud migrate` после push**; `DEFAULT_SETTINGS.bell =
true`; VK — `settings[peerId].bell` (undefined = вкл), helper `bellOnOf`;
клавиатурные строители подписывают кнопку по подписке (параметры bellMode/
bellfull-payload'ы убраны); определение «показан» — сравнение текста сообщения
с `upcoming*`/фокус-рендером (префикс); `dev/sdk-mock/db.js` — персист `bell`.

Проверено (repl): клик1 — «список событий», ММ-ДД, кнопка 🔔 (подписка не
тронута); клик2 — «подписка отключена», ГГГГММДД, 🔕; клик3 — «подписка
включена», ММ-ДД, 🔔; фокус — то же (клик1 показывает по подписке, клик2 по
показанному переключает); подписка переживает перезапуск repl; даты смерти
и 🗑 в фокусе на месте. `node --check` ×4, `dev/sync-check.mjs`,
`lunarreturns.js test` — OK.

Деплой ТГ: `npx tgcloud status` → `push` → **`migrate`** (новая колонка
settings.bell).
