# 20261027 — PDF: годы жизни вместо «_»; ярлыки родства через супруга

## План
1. **PDF-диаграмма (chartModel, `tgcloud/lib/chart.js` ↔ `lunarreturns.js`).**
   Раньше у персоны без даты смерти при истёкших 80 годах рисовался «_» за
   баром; теперь:
   - при **неизвестной** смерти — не рисуем ничего (убран «_»);
   - при **известной** смерти — за баром пишем N (прожитых лет, `death −
     birth`, без «†»).
2. **Ярлыки родства через супруга (kinLabel, `tgcloud/lib/kinship.js` ↔
   `lunarreturns.js`).** Новые композитные ярлыки-дополнения: «отец жены»,
   «племянник мужа», «отец жены внука», «мать двоюродного брата» — `to` —
   кровная родня X (сиблинги/дети/дядья-тётья/родители `to`), а X связан с
   цитируемым (часто по браку). Ограничитель глубины браковых шагов `depth<2`
   (иначе «муж жены мужа…» зациклится). В `genLabel` добавлены родительные
   «муж/жена/супруг». Так как kinLabel — одна функция, обновление автоматически
   действует во всех местах: 🔔-списки (focusListText), PDF-колонка «Связь Год»,
   reply-связи.
3. **Тесты.** `dev/sync-check.mjs`: фикстура «Отец Снохи 1952» + пара
   (Отец Снохи → Сноха); новый раздел-кейсы «отец жены», «племянник мужа»
   (Мать → Двоюродный), «отец жены внука» (Дед → Отец Снохи); «Чужая» теперь
   «мать двоюродного брата» (было «»).
