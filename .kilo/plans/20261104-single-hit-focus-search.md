## Приложение 2: единый протокол перелива «голова + ✂️⏳ → файл → ✂️»

По просьбе заказчика: голова + «✂️⏳» вместо длинного текста, ВЕСЬ список/
пачка — файлом (не остаток), файл цеплется тем же сообщением; после
прицепления правкой снимается «⏳», «✂️» остаётся финальным признаком
«не влезло — полное в файле» (правка, не повторная посылка — вложение
хранится; ТГ — editMessageText, ВК — messages.edit с message). Охваченные
места (ТГ → ВК):
- панель поиска при одном попадании (message.js): head+строки+«✂️⏳», после
  sendDocument правка text=«…✂️» — ВК поиск: messages.edit message =
  head+tail+«✂️», фоллбек — правка «✂️» + файл отдельным сообщением;
- «-+=» на фокусе (callback_query focflat: editText head+«✂️⏳»,
  tailDoc finalText head+«✂️») — ВК foc:flat editOrigin(head+✂️⏳) +
  editOriginDoc + editOrigin(head+✂️);
- пачка чата «-+=» чат-кнопка (callback_query flat: editText «Древо
  чата\n✂️⏳» + tailDoc «✂️») — ВК payload flat editOrigin(«Древо
  чата\n✂️⏳») + editOriginDoc + editOrigin(«✂️»);
- подтверждение 🗑 (del, .txt) — editText(голова+✂️⏳) + tailDoc(✂️) — ВК
  payload del editOrigin(head+✂️⏳) + editOriginDoc + editOrigin(✂️);
- «/links» и 🔗 (sendFlatPack lib/bot.js: sendMessage(head+✂️⏳) + async
  sendDocument + editMessageText head+✂️) — ВК /links (head0+✂️⏳ + async
  doc + messages.edit message=head0+✂️, при неудаче правка «✂️» + файл
  отдельным сообщением);
- большой список поиска «/Имя» (message.js: sendMessage(head+✂️⏳) + async
  .txt + editMessageText ✂️) — ВК search (messages.edit message=head+✂️,
  аналогичный фоллбек);
- 🔔-список чата (bell) — по-прежнему без файла (текст отрезается) — не
  трогали.

Проверено: репл на большой ветви (200 детей; /Иван — панель поиска,
/Дитя — большой список, /links) в обоих ботах — виден «✂️⏳», затем
вложение, затем финальный текст «✂️» без «⏳».

## Приложение 3: метка «не для прививки» перед головой

NOT_FOR_GRAFT («#not for cut and graft») в переделанных чтениях:
-tap «-+=» (пачка ВЕТВИ — панель поиска при одном попадании, «-+=»/foc:flat,
/links-ветвь, sendFlatPack(key)): ВЛЕЗАЕТ — без метки (реплай правленной
пачкой на цитату заменяет ветвь — фича сохранена); НЕ ВЛЕЗАЕТ — метка перед
головой (и в файлах — «✂️⏳ → файл → ✂️»);
- ДНК (пачка РОМБА — древо чата, radiñar 🧬): метка была всегда (первой
строкой пачки chatFlatText) и осталась — короткая (видна после головы
изнутри пачки), перелив — метой перед головой;
- списки (большой поиск, 🗑-список) — метка перед головой при переливе.
lib/bot.js экспортирует NOT_FOR_GRAFT; в ВК `withGraftMark(t)` — BOM + метка,
если текст её не несёт (пачка ромба уже с меткой — не дублируем).

/links — с меткой) — ТГ и ВК дословно.
