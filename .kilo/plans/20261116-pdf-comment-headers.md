fix(chart): set annotation dates for modern PDF.js comments

## План

- Новый CommentPopup PDF.js не выводит /T, а форматирует отсутствующую дату
  как Unix epoch. Сохранить /T для прежних просмотрщиков и общий /Contents,
  добавить реальную дату создания /CreationDate и изменения /M.
- Проверить Unicode, дедупликацию полного текста, даты и ссылки PDF.
- Запустить PDF-регрессии, sync-check и офлайн-интерфейсы TG/VK с изоляцией БД.

Источник: https://github.com/mozilla/pdf.js/blob/master/web/comment_manager.js
(CommentPopup.toggle: форматирование даты без проверки null; /T не используется).
Точная сборка Firefox 160 Windows локально недоступна.

## Уточнение

Добавление заголовка в /Contents отменено по замечанию пользователя:
одинаковая роспись должна переиспользоваться даже при разных /T.
Новый интерфейс Firefox продолжит показывать дату вместо /T; исправление
метаданных устраняет только ложную дату 1970 года.

## Отчёт

### Дополнение: время и /M

Убрать необязательное /CreationDate. Передавать h/m из записей обоих ботов
в строки и фантомных детей диаграммы. В /M переводить московское время
в UTC (минус три часа с переносом даты), при null брать 12:00 МСК.
Сохранить правила дополнения неполных дат и дедупликацию /Contents.

### Дополнение: дата из заголовка

По запросу пользователя полную дату ГГГГ-ММ-ДД после имени в /T
использовать в /CreationDate и /M вместо даты генерации. По уточнению:
год преобразовать в ГГГГ-01-01, год и месяц в ГГГГ-ММ-01.
Только при отсутствии даты использовать дату генерации. /Contents не менять.

- После окончательных уточнений оставлено только /M: дата персоны из /T
  с дополнением отсутствующих месяца/дня до 01 и время рождения из БД.
  При null используется 12:00 МСК. Перевод в UTC: минус три часа, включая
  перенос на предыдущие сутки/месяц/год. /CreationDate удалено.
- /T и дедупликация /Contents оставлены без изменений.
- Регрессии проверяют формат дат и общий объект текста для разных заголовков.
- Пройдены node dev/sync-check.mjs, node dev/pdf-radius-check.mjs
  (включая изолированные TG/VK repl, импорт GED, PDF и колокольчик
  на Romanov_family.ged.txt), git diff --check.
- Визуальная проверка Firefox Windows не выполнялась, деплоя не было.
- Повторные прогоны после уточнений прошли; добавлены сценарии полной,
  приблизительной даты, года, года с месяцем и отсутствия даты.
- Время передаётся обоими адаптерами, включая фантомных детей; проверены
  null, 00:00, 02:45, 12:34, 23:59 и перенос на предыдущий год.
  Полный PDF/repl-прогон и sync-check повторно прошли после изменения времени.
