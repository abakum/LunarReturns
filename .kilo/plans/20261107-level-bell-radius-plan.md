feat(tree): level-based bell radius via blood+marriage+full-sibling BFS (VK + TG)

## План

Список 🔔 (/bellN, фокус-радиус) перевести с «ромба» (u+d−1 слов цепочки) на
«жизненные» уровни родни:

- уровень 1 — родители, дети, супруг, полнокровные сиблинги (по одному шагу
  каждого вида ребра: кровь, брак, полнокровное родство);
- далее уровни = уровень 1 каждого узла предыдущего («отец жены» и «брат
  жены» уже на 2️⃣ — это главная цель);
- полукровные сиблинги (общий ровно 1 родитель при обоих известных) —
  без сиблинг-ребра: путь «вверх+вниз» = 2 уровня, ярлык «сын отца/дочь
  матери» (2 слова = 2 шага);
- сводные (дети нового супруга родителя) — путь «вверх+брак+вниз» = 3
  уровня, ярлыки «сын жены отца» / «сын мужа матери»;
- неполные данные (у одной из сторон известен только общий родитель) —
  считать полнокровными (лакуны не наказывать);
- уровни = числу слов fynny-ярлыка (инвариант, за которым следит
  схем-выбор ребра);
- экспорт 🧬/PDF остаётся на старом кровном ромбе (не расширять радиус PDF);
- супруги доклеиваются как раньше (focusWithSpouses + словесный фильтр
  доклеенных), фильтр ярлыками остаётся вторым этапом.

Схема: двухступенчатая — дешёвый BFS-префильтр по объединённому графу
(кровь 1, брак 1, сиблинг-ребро только полнокровным), затем существующий
фильтр ярлыками (kinLabel ≤ radius слов) как есть.

## Реализация

- `focusGraphDist(pairs, spousePairs, key, radius)` — BFS по объединённому
  графу, Map ключ → дистанция; сиблинг-рёбра — только детям одной
  родительской пары (parentsOf длина 2, оба родителя сгруппированы
  sorted-ключом «родитель1|родитель2»). Ребёнок с 1 известным родителем
  в группы не попадает — сиблинг-ребра у него нет, добирается «вверх+вниз»:
  для дистаниции это 2 вместо 1 (ярлык при лакуне всё равно «брат/сестра»
  — kinLabel наказывает лакуны, граф не наказывает — расходится на шаг,
  принято компромиссом: ошибка в меньшую сторону ищется надёжнее).
- `focusListKeys(pairs, spousePairs, key, radius, sexOf, levels)`:
  levels=true → уровневый core (focusGraphKeys), false/undefined → старый
  кровный ромб (экспорт 🧬/PDF); далее супруги доклеиваются и фильтруются
  словами ярлыка, как раньше.
- `focusDepth(pairs, spousePairs, key)` — максимальная дистанция BFS,
  капнутое 5 (5️⃣ = есть родня за пределами 5 уровней); цифры радиуса
  кнопок следуют за уровнями.
- `kinship.js`: `fullSiblings(parentsOf, X, Y, k)` — общих родителей ≥ 2,
  при лакунах (у стороны ≤1 известен родитель) возвращает true;
  боковая цепочка полукровке — «сын отца/дочь матери», сводному — через
  брак; исправлен баг `a ? ups[a−2] : from` (старый, до этой задачи):
  при a=1 сиблинг стороны героя — сам герой, а обращение шло к
  ups[−1] = undefined; правильно `a > 1 ? ups[a−2] : from`.
