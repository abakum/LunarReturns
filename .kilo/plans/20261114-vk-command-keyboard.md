fix(vk): omit absent keyboard when editing command exports

# План

Исправить messages.edit командного фокусного /gedcom: kb по умолчанию null,
URLSearchParams превращает его в строку null, которую VK отклоняет как JSON
клавиатуры. Передавать keyboard только при наличии клавиатуры в обеих правках
вложения/текста. Ужесточить VK REPL-мок для null/некорректной клавиатуры;
проверить командный и кнопочный экспорты, синхронность и оба REPL.

# Отчёт

В обеих правках фокусного GEDCOM-экспорта keyboard передаётся только при
наличии клавиатуры. Командный ответ без кнопок больше не отправляет null.
VK REPL валидирует структуру keyboard для messages.send/messages.edit;
интеграционный тест отклоняет журнал с ошибкой keyboard contains incorrect JSON,
не позволяя запасной отправке файла скрыть дефект.

обоих REPL с командами/кнопками, экспортом и прививкой.
