# Фокус-радиус: «ромб» — вертикальный обрез вверх и вниз

Дата: 2026-10-21. Статус: реализовано, sync-check зелёный.

## Задача (формулировка пользователя)

Радиус родни сейчас обрезал вверх (предки ≤ r поколений), но вниз — нет
(все транзитивные потомки найденных предков, без ограничения — прилетали
правнучатые племянники уже на радиусе 1). Хочется симметрии: по вертикали
по числу поколений (1 = родители-дети, 2 = деды-внуки, …), по ширине — чтобы
пары родитель-ребёнок держались вместе (есть чадо — есть и родители; родитель
в окне — чадо в окне), насколько позволяет окно.

## Решение (согласовано выбором пользователя)

- **Формула — «ромб»**: узел включён, если существует путь от эго с ≤ r шагами
  «вверх» и ≤ r шагами «вниз». Реализация — обход состояний (узел, вверх, вниз)
  с парето-доминированием: на узле держится список недоминируемых векторов
  [u, d]; окно u ≤ r && d ≤ r.
- **Супруги** — как раньше прицепом (`focusWithSpouses`: супруг добавляется,
  только если половина пары уже в множестве).
- **Цифры радиуса 2–5** на клавиатуре фокуса — по `max(глубина предков,
  глубина потомков)` вместо прежней чистой глубины предков.

Составы (эго Сын, фикстура sync-check): r1 = родители + сиблинги (Чужой,
Отец, Мать, Дочь); r2 = + Дед, Бабка, Тётя, Двоюродный, Племянник; r3 =
+ Прадед, Дядька/Тётка, Внучатый, ДвПлем, ДвВнуч? (ДвВнуч u2d4 → r4), Кузина
(u4d2 → r4), Троюродный (u4d3 → r4), Чужая (u3d2 → r3). Сиблинг = u1d1,
дядя = u2d1, двоюродный = u2d2, племянник = u1d2 — «степень кузена и
удаление» прямо отображаются на окно.

## Правки

- `lunarreturns.js`: `focusKeys` (парето-ромб), `focusDepth` (max предки/потомки).
- `tgcloud/lib/bot.js`: те же две функции дословно.
- `dev/sync-check.mjs`: комментарии; состав-серты радиусов 1–5, включая
  ромб-границы (r1 без Племянника, r2 без Внучатого/ДвПлем/Правнучатого,
  r3 без Брата Прадеда (u4), r4 с Кузиной/Троюродным/Правнучатым);
  focusDepth-кейс «потомки есть, родителей нет» → 2 по потомкам.

## Валидация

1. `node dev/sync-check.mjs` ✓ (ВК/ТГ дословно синхронны).
2. `node lunarreturns.js test "..."` ✓; `lunarreturns.db` не создаётся.
3. `node --check` обеих копий ✓.
4. `README.md` без упоминаний радиуса — документацию править не потребовалось.


## Границы поведения (зафиксированы, не чиним)

- Ромб не гарантирует полноту семьи за окном: второй родитель ребёнка может
  оказаться за u-пределом (Чужая — мать Двоюродного — появляется только в r3),
  супруги не-кровные — только прицепом `focusWithSpouses`.
- «Если есть чадо — родители, и наоборот» выполняется там, где оба конца
  помещаются в окно; транзитивного разрастания ширины нет — это и была цель.
