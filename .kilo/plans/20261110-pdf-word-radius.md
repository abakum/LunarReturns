fix(chart): enforce PDF word radius after cheap candidate selection

## План

1. Сохранить cheap prefix focusKeys (u+d-1<=R); для PDF учитывать также
   ограниченные брачные переходы без veto графовой дистанцией.
2. После добавления бездатных супругов проверять все PDF person rows:
   герой либо непустой kinLabel с числом слов <= R. Кэш подписей локален
   одному render, используется повторно для рисования.
3. Не менять GED/TXT/CSV, bell, fullSiblings и алгоритм kinLabel.
4. Добавить независимые регрессии R1/R2 для ABT/exact, неполных родителей,
   брачных цепочек, бездатных супругов и вычисления только кандидатов.
5. Обновить pdf.md; выполнить sync-check, chart/PDF проверки и реальные
   изолированные TG/VK REPL сценарии, не трогая основные БД.

Существующие dirty changes сохраняются. Commit и deploy не выполняются.

## Отчёт

- `focusKeys` сохраняет исходный cheap prefix `u+d-1<=R`. Необязательный
  четвёртый аргумент добавляет ограниченные брачные переходы только для PDF;
  после брака новый кровный участок получает тот же нижний предел. Прежние
  вызовы экспорта и bell не меняют поведения.
- В обоих `chartFor` общий `chartRows` фильтрует итоговые строки после
  добавления якорных бездатных супругов. Нужен непустой ярлык <= R слов,
  герой освобождён от проверки. Графового veto и ABT union больше нет.
- Локальные брачные рёбра бездатных супругов обеспечивают корректный ярлык.
  После фильтрации пересобираются видимые связи и семейные отметки.
- `rel.labels` содержит локальный Map одного render; `chartModel` повторно
  использует подписи, не вызывая kinLabel второй раз. Пол доступен также для
  промежуточных персон полного графа, но их ярлыки не вычисляются заранее.
- `pdf.md` обновлён: правило кандидаты -> слова, различия экспортов,
  отсутствие ABT-исключения, стоимость и остаточные ограничения.
- Новая `dev/pdf-radius-check.mjs`: независимые ожидания для missing-parent
  sibling, half brother, героя, цепочек браков, кровных участков по обе стороны
  брака, бездатных супругов и локального кэша. Счётчик реальных вызовов через
  VM подтверждает 5 kinLabel на кандидатов R1 при 1000 посторонних строках,
  отрисовка не добавляет вызовов. В VK REPL trace добавлены исходные байты
  upload в base64 для извлечения настоящего PDF без повреждения UTF-8.
