- В обоих ботах использовать одинаковую основу снаружи и внутри: `Древо чата` для общего экспорта, `Имя ДР` для фокуса, без радиуса, даты смерти и транслитерации. Для записи XHTML поставить UTF-8-флаг в обоих заголовках ZIP.
- Закодировать путь в манифесте и оглавлении, обновить подсказку и локальную пробную сборку. Проверить EPUBCheck, извлечение файла и выгрузки TG/VK.

## Отчёт

- `/epubN`, `/gedcomN` и 🧬 в TG/VK используют `Древо чата` либо `Имя ДР` для `.epub` и одноимённого `.xhtml` в `EPUB/`. Пробный генератор использует общий код, подсказка указывает фактический внутренний путь.
- `npm run test:viewer`, `node dev/sync-check.mjs` и `git diff --check` прошли. `jar` извлёк кириллическое имя без искажений, Chromium открыл XHTML и построил фокус. EPUBCheck не нашёл ошибок; `PKG-010` предупреждает о пробелах для старых читалок. Локальные сборки Info-ZIP искажают кириллицу, поэтому REPL-проверка проверяет флаги и читает UTF-8-имя напрямую из ZIP. Живая доставка с новым именем не проверялась.
