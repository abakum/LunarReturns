# 20261026 — Поиск по плоскому древу: `/Иван`, `/-Пётр`, `--Иван`, `/=…`, `/ текст`

## План

Ответ на `/запрос` — список строк пачки «плоское древо» чата в порядке древа:

- **Префикс** (`/Иван`, `/Иван Петрович`, `/Иван Петрович Сидоров`): строки,
  начинающиеся с запроса; ведущие маркеры строк (`-`/`=`/`+`-серии) сняты.
- **Маркер в запросе**: `/-Пётр` — только мужчины глубины 0 (серия `-`×1),
  `/--Иван` — мужчины глубины 1, `/=Мария` — женщины глубины 0, `/==…` — 1 и т.д.:
  серия маркеров запроса должна совпасть с серией строки дословно
  (безмарковые строки и `+`-свадьбы исключаются).
- **Подстрока** (`/ текст` — пробел сразу после `/`): подстрока в строке без
  маркера (имя, дата, место, примечание, свадьба).
- Регистр не учитывается; сравнение литеральное (без регэкспа).
- Пусто → справка (HELP + клавиатура чата/роли, как на `/start`).
- Известные команды (`/start`, `/today`, `/gedcom[1-5]`, `/links`, голый `/`)
  не тронуты; поиск — только для остальных `/...`.

## Реализация

- **Чистая логика** `flatSearch(flat, query)` — дословно в обеих копиях:
  `tgcloud/lib/bot.js` (export) и `lunarreturns.js` (+ `__test`). Разбор запроса
  (`/`, серия маркеров одним символом, пробел = подстрока) + фильтр строк
  `chatFlatText`.
- **ТГ** `tgcloud/handlers/message.js`: бывшее `if (text.startsWith("/")) return;`
  → поиск → `sendLong` списка или HELP+`startMarkup`.
- **ВК** `lunarreturns.js` `handleMessage()`: после `/links`, до гедкома/пачки —
  поиск → `messagesSend` или HELP+клавиатура (`relKeyboard`/owner/bell).
- **HELP** обеих копий дополнен строкой про поиск.
- **Дополнение (тот же день):** запрос из одних маркеров — `/-`, `/--`, `/=…`,
  `/++` и т.д. — список ВСЕХ строк с этой серией маркеров (все мужчины/
  женщины/свадьбы уровня); `/ маркер пробел` — то же (`/- `). В `flatSearch`:
  при пустом тексте после маркера фильтр только по серии.

  примечании/пустой запрос) + точечные ожидания результата. Проходит.

  `/=Мария`, `/==Мария`, `/ Анна`, `/ пермь`, `/ 1996` — списки совпадают
  с плоским древом и между платформами; `/ нет-такого` и `/-` — хелп.
  Триггеры/пачки не задеты (поиск только для `/...`). `git checkout -- dev/tg-db.json` сделан.
