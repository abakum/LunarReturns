feat(viewer): show tree navigation tips on desktop and mobile

## План

- Показывать подсказку на десктопе и мобильном экране и добавить ссылку на описание родословной росписи.
- Сохранить закрытие подсказки на сессию, пересобрать просмотрщик и проверить браузер и экспорт TG/VK.

## Отчёт

- Подсказка видна при первом открытии на десктопе и мобильном экране. Ссылка «Родословная роспись -+=» открывает документацию в новой вкладке; имя в карточке по-прежнему открывает роспись выбранного человека.
- `npm run build:viewer`, `npm run test:viewer` и `node dev/sync-check.mjs` прошли. Браузерный тест проверяет видимость, адрес ссылки и сохранение закрытия подсказки на обоих экранах.
