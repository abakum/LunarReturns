# Схлопывание пробелов в NAME при импорте GEDCOM

## План

При импорте `.ged` с `1 NAME Имя  /Фамилия/` между именем и фамилией
оказывалось два пробела, что ломало поиск по «Имя Фамилия».

Правка: после снятия слэшей и trim добавлено `.replace(/\s+/g, " ")`
в разборе `NAME` (дословно в обеих копиях логики):

- `lunarreturns.js` (parseGedcom, строка NAME)
- `tgcloud/lib/parse.js` (parseGedcom, строка NAME)

## Отчёт

- Правки применены в обеих копиях.
- Проверка: `parseGedcom("0 HEAD…1 NAME Имя  /Фамилия/")` → `"Имя Фамилия"`.
- `node dev/sync-check.mjs` — ✓ синхронны (23 триггера, гедком-импорт/экспорт,
  плоское древо, связи/семьи/каскад, chartPdf).
- `node lunarreturns.js test "Имя 1963-09-27 12:30 (Пермь)"` — ок.
- Деплой в ТГ не выполнялся (`npx tgcloud push` — по необходимости; схема не менялась).
