# 20261027 — не приходят оповещения ВК-бота (mmdd без дефиса) + `!daily` в vk-repl

## План / проблема

В ВК-боте перестали приходить суточные оповещения о наступлении события
(годовщины в 09:00 МСК). Диагностика по логам (25 окт — таймауты сети, рестарты)
не показывала ошибок отправки; репл не позволял дёргать планировщик.

## Причина

Коммит `43cade5` (SQLite xref store) заменил выборку годовщин: раньше
`rec.d.slice(5).replace("-","")`, стало SQL `substr(birt_d, 6, 5) = ?` с
`mmdd = "MMDD"` (без дефиса), а `substr("1970-10-27", 6, 5)` = `"10-27"` —
сравнение никогда не совпадало, суточная рассылка молчала с момента перехода
на SQLite. ТГ-зеркала у планировщика нет (только ВК), sync-check не задевался.

## Правки

- `lunarreturns.js` `dailyCheck()`: `mmdd` теперь `"MM-DD"` (с дефисом).
- `dev/vk-repl.mjs`: экспорт `dailyCheck`, `mskNowParts` в `__test`; команды
  `!daily` (прогон суточной проверки) и `!date ГГГГ-ММ-ДД [hh]` (подмена
  «сегодня»/часа МСК через `globalThis.__LR_TODAY`/`__LR_HOUR`, `!date off` — отмена).

## Проверка

- репл: триггер на «сегодня» → `!daily` отправляет annual-сообщения обоим
  событиям (персона + свадьба); повторный `!daily` — тишина (дедуп по году);
  `!date 2027-10-27` + `!daily` — возраст 57, отправка уходит (год сменился).
- `node dev/sync-check.mjs` — ✓ синхронно.

## Деплой

`sudo`-копия `/var/lib/lunarreturns/lunarreturns.js` обновить из репо,
`systemctl restart lunarreturns`. Дедуп не потеряет пропущенные юбилеи за
прошедшие дни (sent пишет по году отправки), но и догонять их не будет —
только сегодняшний.
