# Формат сводки гедком-импорта и даты в ошибке «слишком молод»

## Задача

1. После замены древа .ged-файлом вместо «✅ Добавлено: персон 1940, связей 2419,
   свадеб 144» выводить как у импорта пачки: «✅ древо: добавлено N персон,
   X пар, Y детей».
2. В ошибке возраста добавлять даты: «родитель «Ефросинья _Абакумова
   ГГГГ-ММ-ДД» слишком молод для «Варвара Абакумова ГГГГ-ММ-ДД»».

## Правки (обе копии: lunarreturns.js + tgcloud/lib/bot.js)

- `importGedcom` считает и возвращает `{persons, fams, links, errors: []}`:
  fams — вставленные fam-строки, links (детей) — вставленные chil-строки
  ( formerly links = рёбра links-таблицы, weddings — датные свадьбы).
  Заполнение links-таблицы сохранено, счётчики рёбер/свадеб убраны.
- `replaceWithGedcom`: `head: treeReport(r)` — общий формат с пачкой.
- `applyTree`, ошибка возраста: `nameN(…) + " " + pd` / `+ " " + cd` — даты
  рождения родителя и ребёнка (ошибка гарантирует их наличие).

Не менялось: предпроскоп подтверждения «🧬 Файл …: персон N, связей M,
свадеб K. Заменить…?» (gedStats).

## Дополнение (2026-10-25, позже): предпросмотр тоже в персон/пар/детей

`gedStats` (чистая логика, обе копии) переведён на подсчёт как `importGedcom`:
persons — персон с датой, fams — все FAM файла, links — дети FAM (персоны с
датой). Текст подтверждения в обоих ботах: «🧬 Файл …: персон N, пар X,
детей Y. Заменить события чата деревом?». Числа совпадают с итоговым
«✅ древо: добавлено …» после замены (проверено: Romanov 57/13/43 в обоих
ботах, sync-check ✅).
