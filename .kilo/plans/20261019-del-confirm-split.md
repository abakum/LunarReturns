# Подтверждение удаления: длинный список не показывался

## План

Симптом: при 🗑 (удаление всех событий чата) в ВК виден только тост «подтвердите
удаление», сообщение со списком событий и кнопками Да/Нет не появляется.

Причина: в ветке `del` (обе копии — VK `lunarreturns.js` и ТГ
`tgcloud/handlers/callback_query.js`) «заголовок + список» шлётся одной правкой
без разбиения. При длине > 4096 символов API отклоняет и `messages.edit`, и
фолбэк-отправку целиком (в ТГ ошибка глушится `.catch(() => {})`) — пользователь
остаётся с одним тостом. Ветки 🔔/🧬/фокуса уже используют `splitText` → правка
первого куска с кнопками → досылка хвоста; ветка `del` — нет.

Шаги:

1. VK `del`: `splitText(...)` → `editOrigin(parts[0], kb)` → `messagesSend`
   для остатка (как ветка 🔔).
2. ТГ `del`: тот же паттерн через `splitText` + `editText(parts[0], markup)` +
   `api.sendMessage` для остатка (как ветка фокуса).
3. Проверки: `node --check` обеих копий, `node dev/sync-check.mjs`,
   repl-сценарий с ~220 событиями, sanity `splitText`, `lunarreturns.js test`.

## Отчёт (2026-10-19)

Изменения:

- `lunarreturns.js` ветка `del` (≈2096): список режется `splitText`, начало с
  кнопками 🗑/❌ правит исходное сообщение, хвост досылается.
- `tgcloud/handlers/callback_query.js` ветка `del` (≈87): аналогично —
  `splitText` + `editText(parts[0], inline_keyboard …)` + `api.sendMessage`
  для остатка.

Проверено:

- `node --check` обеих файлов — OK.
- `node dev/sync-check.mjs` — «ВК и ТГ синхронны» (чистая логика не менялась,
  правка только интерфейсного слоя).
- repl (`--fresh --admin --chat 7`, 220 событий, `/2 1`): toast
  «Удалить все события чата?» → правка сообщения [2] заголовком + началом
  списка, клавиатура «🗑 удалить всё / ❌ отмена» на нём, хвост — одним
  продолжением-сообщением [443].
- VK `splitText` на 220 строках (5171 симв.): 2 куска, макс 3997, первый
  начинается заголовком, последний кончается последним событием.
- `node lunarreturns.js test "Имя 1963-09-27 12:30 (Пермь)"` — OK.

Пуш в облако ТГ: `npx tgcloud status` → `push` (схема не менялась, `migrate`
не нужен).
