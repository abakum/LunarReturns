## План

Два дефекта после уровневого радиуса (20261107-level-bell-radius,
20261107-chart-halfsib-pdf):

1. **PDF теряет персоны с примерными датами.** sendGedPdf/sendGedArtifacts
   стали строить персон чарта уровневым focusListKeys (levels=true — «как
   🔔/bellN»), но выдуманные даты бездатных (импорт: birtAbt 15 = EST-день)
   существуют именно ради шкалы PDF: полукровный сиблинг с EST на 1️⃣
   выпадал из строк чарта (levels-дистанция 2), оставаясь точкой-фантомом.
   Цель: персон чарта = fynny-ромб (levels) ПЛЮС персоны с примерной ДР
   (abt != 0 — ABT/CAL/BEF/AFT/EST) из keys-ромба экспорта, не взирая на
   квалификатор; точнодатированная полукровка остаётся точкой (замысел
   20261107-chart-halfsib-pdf сохраняется для точных дат).

2. **Рассинхрон ВК/ТГ: ВК терял Феодору Алексеевну (Romanov_family.ged).**
   - ВК linkPairs: `SELECT p,c FROM links WHERE chat=?` без ORDER BY идёт
     по индексу UNIQUE(chat,p,c) — по алфавиту; ТГ сортирует по id.
   - focusGraphDist строил сиблинговое ребро звездой от kids[0]
     (`kids[0]↔kids[i]`): при порядке детей «Наталья, Пётр, Феодора»
     (алфавит ВК) Пётр—Феодора = 2 шага — Феодора выпадала из levels r1,
     хотя полнокровная сестра. Дистанция сиблингов обязана быть 1 всегда.

Правки (зеркально lunarreturns.js и tgcloud/lib/bot.js):
- focusGraphDist: клика всех пар детей одной родительской пары.
- ВК linkPairs: ORDER BY id (порядок как в ТГ).
- sendGedArtifacts/sendGedPdf: chartKeys = levels-ромб ∪ (keys ∩ abt-персоны).
