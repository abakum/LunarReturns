# Новая грамматика плоского древа: свадьба «+дата», вторая половина строкой ниже

Дата: 2026-10-23 (согласование той же датой). Развитие плоского древа
(20261022-flat-tree-input-plan.md) и семьи с одной половиной
(20261023-wife-only-weddings.md). Прежний пакетный ввод маркировал
импортированного супруга полом (`+-Имя` / `+=Имя`), а строка свадьбы шла
отдельно датами. Согласовано заменить: строка «`+дата` [дата развода]
(место)» — свадьба, вторая половина идёт **следующей строкой без маркера
пола** (пол выводится из партнёра); «`+`» — свадьба без известной даты.
Старые `+-`/`+=` удалены из грамматики (строки стали ошибками с подсказкой).

## План

1. `parseTreeLine` (tgcloud/lib/parse.js + дословно lunarreturns.js):
   - маркер «+» → `{k:'wp', rec, note}` (даты через вынесенный хелпер
     `weddingRecOf`; пустой хвост → `rec:{}` без даты);
   - строка одних дат → `{k:'w'}` без ожидания супруга (свадьба уже
     известной пары);
   - имя без маркера → `{k:'sp'}` (не ошибка «строка без маркера»);
   - «+» с хвостом без дат («+=Имя…») → понятная ошибка про новую форму.
2. `parseTree` — отложенная привязка: `pw = {wIdx, spi, line}` (открытое «+»);
   привязка `bindW` по стеку с чексками возраста (≥16) и живости — по всем
   кандидатам, кроме стороны, которую заменит новый супруг (`excl` —
   сторона spouseLine). Слот половины: свободная половина семьи; при
   повторном браке (обе заняты, копия семьи наверх) — замена стороны
   spouseLine. Пол половины = пол противоположной стороны.
3. `applyTree` (ветка цитаты, обе копии): убраны `sxSex` и проверка «пол
   супруга совпадает с цитируемым» — осталась только «пол цитируемого
   неизвестен» (однополая проверка исчезла: пол супруга в грамматике не
   задаётся). Инвариант `w0` сохранён.
4. Вывод `flatTreeText`/`chatFlatText` (обе копии) — симметрично вводу:
   семья → строка «`+дата`» (или «`+`») + имя половины без маркера (уже
   напечатанная — именной заглушкой); `wedPlus` выделен (вторая дата =
   развод).
5. Тексты: HELP (lib/bot.js), шапки comment-блоков ПЛОСКОЕ ДРЕВО в обеих
   копиях, комментарии handlers/message.js (детект пачки `/^[-+=]/` не
   менялся) и раздела вывода.
6. Тесты: сценарии dev/sync-check.mjs TREE1–TREE5 переведены на новую
   грамматику; round-trip вывод→ввод прогоняется вручную.
