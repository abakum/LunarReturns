## План

В VK sendGedArtifacts после каждой успешной загрузки выполнять правку исходного сообщения со всеми уже готовыми вложениями и прежним текстом с часами. Ошибка промежуточной правки не должна терять загруженный документ или мешать следующим загрузкам. По завершении сохранить существующую финальную правку без часов и с ошибками отдельных файлов. TG не менять: его API не позволяет дополнять вложения одного текстового сообщения так же, как VK. Проверить накопление вложений и сохранение часов в тестах, оба REPL и sync-check; без деплоя.

## Отчёт

Реализовано: после каждого успешного vkUploadDoc исходник правится с накопленным набором attachment и holdTxt (часы сохраняются). Клавиатура и адресация исходника сохраняются. Отказ промежуточной правки только логируется; загруженные документы остаются в массиве для следующих/финальной правок. Финальная обработка частичных ошибок не изменена.

Успешно выполнены a3-repl-check, sync-check, diff --check. VM-проверки подтверждают правку после каждого успешного файла, накопление вложений, один ID сообщения и часы до финала при успехе и отказе каждого отдельного файла. Оба REPL проходят; логи `/tmp/lr-a3-repl-2IopKS`. Ошибка самого промежуточного edit проверена по коду, отдельно не имитировалась. Деплой и коммит не выполнялись.
