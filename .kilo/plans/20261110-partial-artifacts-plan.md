## План

В sendGedArtifacts VK загружать каждый документ независимо с существующими повторами. После отказа одного продолжать остальные, прикрепить все успешные результаты и вместо часов перечислить неудавшиеся файлы. Если не загрузилось ничего, показать ошибку в исходнике, без отдельного дубля. Проверить отказ каждого из трёх файлов и всех файлов, затем зеркальные REPL и sync-check. TG media group в этой задаче не менять: предоставленный журнал относится к VK.

## Отчёт

Реализовано: каждый из GED/PDF/TXT загружается в собственном try/catch; успешные вложения накапливаются, ошибки перечисляются в финальном тексте вместо часов. Неудача GED не препятствует PDF/TXT, неудача TXT не теряет GED/PDF. При полном отказе используется обработчик ошибки исходного сообщения без дубля. Каждый файл сохраняет существующие повторы.

Успешно: `node dev/a3-repl-check.mjs`, `node dev/sync-check.mjs`, `git diff --check`. В a3-repl-check добавлена VM-проверка производственного блока загрузки: отказ каждого файла отдельно, всех файлов и полностью успешный исход; все три попытки файлов выполняются, успешные результаты сохраняются, ошибка указывает имя. Зеркальные REPL проходят, логи `/tmp/lr-a3-repl-jhQY4m`. Реальный VK API не вызывался, живой таймаут не воспроизводился. Деплой и коммит не выполнялись.
