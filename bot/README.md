# lunarreturns.js — VK-бот юбилеев

Бот сообщества ВКонтакте отвечает списком лунно-солнечных юбилеев на сообщение
вида:

```
Костя 19630927
Дедушка Костя 1963-09-27 14:30
Дедушка Костя 1963-09-27 12:30 (МСК+2)
Дедушка Костя 1963-09-27 12:30 (Пермь)
Дедушка Костя 1963-09-27 12:30 UTC+5
```

`+` в имени — пара (`Костя+Галя 19780512`), в годовщины добавляются названия
свадеб (серебряная, золотая…). Город — из списка приложения LunarReturns
(учтены исторические сдвиги часов), сдвиг — `МСК±N` / `UTC±N` / `ГМТ±N`.
Без времени берётся полдень, без пояса — МСК.

Запись сохраняется в `db.json` рядом со скриптом; каждый год в день рождения
(по МСК) в 09:00 бот сам отправляет обновлённый список юбилеев в тот же диалог.

## Установка

Нужен только Node.js ≥ 18 (зависимостей нет, `npm install` не требуется).

1. В настройках сообщества ВК: Управление → Работа с API → Создать ключ,
   права: **Сообщения сообщества** (и Разрешить сообщения сообщества).
   Включите «Возможности ботов» → Long Poll API.
2. Запуск:

```
VK_TOKEN=vk1.a.... node lunarreturns.js
```

или создайте файл `.env` рядом со скриптом:

```
VK_TOKEN=vk1.a....
```

Необязательная переменная `VK_GROUP_ID` — если токен групповой, но групп
несколько.

## Проверка без токена

```
node lunarreturns.js test "Дедушка Костя 1963-09-27 12:30 (Пермь)"
```

Печатает разбор (перевод в МСК) и список юбилеев, не подключаясь к ВК.

Логика расчёта — дословный порт из `LunarReturns/index.html` (`moonNew`,
`legend`, `la`), вывод совпадает с приложением.
